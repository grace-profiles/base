You can always get information about the provided command and available features executing
`grace profile-info base`,

You will see an output similar to:

[source,console]
----

There are some profiles extended from `base`,

* link:https://github.com/grace-profiles/plugin[Plugin]
* link:https://github.com/grace-profiles/rest-api[REST API]
* link:https://github.com/grace-profiles/web[Web]
* link:https://github.com/grace-profiles/web-plugin[Web Plugin]

If you want to create your own profile, it can be extended from `base` too,

[source,groovy,subs="attributes"]
----
dependencies {
    profile "org.graceframework.profiles:base:{version}"
}
----
