NOTE: Currently, Grace framework does not provide a direct `upgrade` command, but it may offer this in the future.

The simplest way is to create two different versions of a new application, and then compare the differences between the two versions using the `git-diff` command.

[source,console,subs="attributes"]
----
$ sdk use grace {version}
$ grace -v
$ grace create-app com.example.myapp --grace-version=2024.1.0
$ cd myapp
$ git init && git add . && git commit -m "Generated by Grace 2024.1.0"
$ cd ..
$ grace create-app com.example.myapp --force
$ cd myapp
$ git diff
----
