== create-domain-class

=== Description

Creates a Domain Class.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Domain Class Name
|The name of the Domain Class
|true
|===

=== Usage

[source,console]
----
$ grace create-domain-class [Domain Class Name]
----

=== Examples

[source,console]
----
$ grace create-domain-class Post
$ grace create-domain-class org.blog.Post
----
