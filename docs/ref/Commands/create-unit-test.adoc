== create-unit-test

=== Description

Creates a Unit Test.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Test Name
|The name of the Unit Test
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,console]
----
$ grace create-unit-test [Test Name]
----
