== create-command

=== Description

Creates an Application Command in the `app/commands`.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Command Name
|The name of the Command
|true
|===

=== Usage

[source,console]
----
$ grace create-command [Command Name]
----

=== Examples

[source,console]
----
$ grace create-command Example
| Created app/commands/com/examples/ExampleCommand.groovy
----
