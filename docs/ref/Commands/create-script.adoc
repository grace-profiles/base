== create-script

=== Description

Creates a Groovy script.

=== Arguments

[cols="1,1"]
|===
|**Name**
|**Description**

|Script Name
|The name of the plugin to be created
|===

=== Usage

[source,bash]
----
$ grace create-script [Script Name]
----

=== Examples

The command:

[source,bash]
----
$ grace create-script my-script
----

Creates a script called `src/main/scripts/my-script.groovy` such as:

[source,groovy]
----
description "Example description", "grace script.groovy"

println "Example Script"
----
