== run-script

=== Description

Executes Groovy scripts in a Grace context.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Script Name
|The paths of scripts relative to the project root
|true
|===

=== Usage

[source,console]
----
$ grace run-script [Script Name]
----
