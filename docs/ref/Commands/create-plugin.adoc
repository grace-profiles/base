== create-plugin

=== Description

Creates a dynamic and inline plugin in the `app/plugins`.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Plugin Name
|The name of the Plugin
|true
|===

=== Usage

[source,console]
----
$ grace create-plugin [Plugin Name]
----

=== Examples

[source,console]
----
$ grace create-plugin Taggable
| Created app/plugins/com/examples/TaggableGrailsPlugin.groovy
----
