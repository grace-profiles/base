== asset-pipeline

=== Description

Adds Asset Pipeline to a Grace project.

=== Usage

Add `asset-pipeline-plugin` dependency to build.gradle,

[source,groovy]
----
plugins {
    id "org.graceframework.asset-pipeline"
}

dependencies {
    implementation "org.graceframework.plugins:asset-pipeline-plugin"
}
----
