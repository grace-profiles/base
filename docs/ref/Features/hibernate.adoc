== hibernate

=== Description

Adds GORM Data Hibernate to the project.

=== Usage

Add `grace-boot-hibernate` dependency to build.gradle,

[source,groovy]
----
dependencies {
    implementation "org.graceframework:grace-boot-hibernate"
}
----
