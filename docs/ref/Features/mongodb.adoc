== mongodb

=== Description

Adds GORM for MonogoDB to the project.

=== Usage

Add `grace-boot-mongodb` dependency to build.gradle,

[source,groovy]
----
dependencies {
    implementation "org.graceframework:grace-boot-mongodb"
}
----
